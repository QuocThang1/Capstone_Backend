# Task Management Platform - Backend

**Status:** Ongoing
**Frontend Repository:** https://github.com/QuocThang1/Task_Management_FrontEnd

## Overview
This repository contains the backend architecture for the Agile Task Management Platform. It is engineered to handle complex task routing, real-time data synchronization, and advanced system analytics to optimize team workflows and manage project lifecycles efficiently.

## Technologies Used
* Node.js
* Express.js
* MongoDB
* Socket.io

## Key Features
* **Bottleneck Detection Mechanism:** Engineered an advanced analytical feature to monitor task flow, calculate time-in-status, and automatically identify operational blockages within the Agile workflow.
* **Real-time Event Logging:** Implemented Socket.io server logic to instantly track system changes, log task updates, and broadcast events to all connected clients.
* **RESTful APIs:** Developed secure and scalable endpoints for managing users, projects, Kanban columns, and individual task data.
* **Database Modeling:** Designed structured MongoDB schemas to efficiently map out complex relationships between users, teams, and hierarchical task assignments.
